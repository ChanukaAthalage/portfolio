# Portfolio

Personal portfolio website showcasing my software engineering projects and case studies.

## About

Built by Chanuka Athalage — a software engineer based in Perth, WA, with a Master of Computer Science (Distinction) from Curtin University. This site highlights full-stack projects including [MineGuard](#) (a mining safety incident reporting system) and [StockSense](#) (a deployed inventory management platform with CI/CD).

## Tech Stack

- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Code Review:** CodeRabbit

## Getting Started

\`\`\`bash
npm install
npm run dev
\`\`\`

Open [http://localhost:3000](http://localhost:3000) to view it locally.
